# Проверка хранилища без SwiftProtobuf

Из корня репозитория: `sh Scripts/check-finance-storage.sh`.

Скрипт компилирует настоящие `Financium/Models/Core/*.swift` и проверки через
системный Swift, не скачивая пакеты. Отдельный XCTest target не требуется.

`legacy-fixtures.json` содержит 67 эталонных бинарных записей. Они получены
SwiftProtobuf 1.36.1 из прежнего `finance.pb.swift` до его удаления: по десять
записей Money, Account, Transaction, Budget, Goal, FinanceSettings и семь
Timestamp, созданных из Foundation Date. Значения включают Int64.min/max,
отрицательные суммы, Unicode и NUL в строках, неизвестные поля/enum values,
отсутствующие и явно заданные вложенные сообщения, дробные секунды и даты до
Unix epoch. Это тестовые данные, не содержимое пользовательского хранилища.

Проверки сравнивают новый CloudKit codec с эталонными байтами, включая проход
через Codable. Также проверяются повторные поля, неизвестные wire types,
отказ на повреждённых payloads, перенос месяцев бюджетов, миграция старого
локального JSON, сохранность backup, повторный запуск и восстановление
`finance-cache-v1.json`. Удалять неизвестные поля или менять номера legacy-полей
нельзя: это нарушит совместимость общих счетов с прежними сборками.

На устройстве дополнительно проверить обновление поверх прежней сборки без
удаления приложения: счета, операции, бюджеты разных месяцев, цели и настройки
должны сохраниться после двух запусков. Для CloudKit нужны два iCloud-аккаунта:
проверить приглашение и обмен изменениями между новой и прежней сборками.

Локальный архив v2 не предназначен для отката на прежнюю сборку. Исходный v1
сохраняется рядом как `financium-local.json.v1.backup`; текущие CloudKit payloads
продолжают использовать совместимый бинарный формат.
